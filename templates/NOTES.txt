Nexus {{ .Values.image.tag }} is starting. The first boot takes 1-3 minutes.

1. Wait until it is ready:
   kubectl -n {{ .Release.Namespace }} rollout status deploy/{{ .Release.Name }} --timeout=5m

2. Open the UI (keep the command running), either:
   minikube service {{ .Release.Name }} -n {{ .Release.Namespace }} --url    # then add /nexus to the URL
   kubectl -n {{ .Release.Namespace }} port-forward svc/{{ .Release.Name }} 8081:{{ .Values.service.port }}   # http://localhost:8081/nexus

3. Log in with the default credentials admin / admin123, then change the password.
